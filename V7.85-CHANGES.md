# WebFun V7.85 — Interaction reliability + optical edge cleanup

- Desktop Services mega-menu now has a stable hover corridor and a 260 ms close grace period, so the panel no longer disappears before the pointer reaches a link.
- Keyboard focus keeps the Services menu open while focus remains inside the component.
- Gradient CTA edge artifact removed: gradients paint through the full rounded box instead of revealing the parent surface through a transparent 1 px seam.
- Final CTA button now has no decorative border; focus-visible remains handled by the accessibility outline.
- Touch/mobile CTAs use a short blue → violet → lilac `:active` state instead of relying on desktop hover.
- Mobile section tags are locked to the same left axis as their headings.
- Hero “mais” is fully opaque and slightly more saturated in dark mode.
