# Catálogo mestre de projetos — Webfun

Este arquivo organiza a vitrine de projetos sem misturar a regra de exibição com o destino dos CTAs.

## Regra de navegação

- Cliente real online: `Ver projeto` abre o site/produto real em nova aba.
- Projeto autoral com demo: `Ver projeto` abre a demo funcional em nova aba.
- Produto próprio online: `Ver projeto` abre o produto publicado em nova aba.
- Projeto sem destino público: o card pode continuar usando o case interno até existir uma demo ou URL definitiva.
- Projeto antigo/offline: não entra automaticamente na vitrine; primeiro revisar imagens, relevância e destino.
