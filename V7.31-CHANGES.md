# WebFun V7.31 — Typography System

- Tipografia mobile padronizada: H1 44px (com proteção para telas muito estreitas), títulos 30px, subtítulos/cards 24px e textos 16px.
- Peso dos títulos padronizado em 500.
- Tags de seção agora são apenas texto em azul, minúsculas, sem badge, fundo, borda ou point.
- Ritmo de linha e espaçamento ajustados para leitura mais limpa no mobile.
- Padrão aplicado globalmente às páginas e principais componentes, reduzindo exceções tipográficas acumuladas.
