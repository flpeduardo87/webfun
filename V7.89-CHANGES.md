# WebFun V7.89 — Hero atmosphere + opaque mega menu

- Home hero gained a restrained layered atmosphere using subtle blue/violet radial light and a soft tonal gradient instead of a flat background.
- Light and dark hero treatments are theme-aware; mobile uses a quieter variant to preserve headline readability.
- Services mega menu is now fully opaque in both themes; page content can no longer show through the panel.
- Dark mega menu was simplified to graphite surfaces + WebFun blue, removing the multicolor icon treatment and violet-heavy hover state.
- Dark mega-menu hover now uses a neutral graphite surface with a single blue icon/accent.
