# WebFun V7.25 — Mobile carousel UX

- Hero carousel now supports native-feeling horizontal swipe on touch devices.
- Featured Projects carousel now supports swipe left/right across the visual/card area.
- 42px swipe threshold prevents accidental slide changes.
- `touch-action: pan-y` preserves normal vertical page scrolling.
- Existing dots remain synchronized and clickable as secondary navigation.
- Removed the large `Estudo conceitual · Website` overlay from Featured Projects artwork.
- Added a compact blue category micro-tag below the project name on mobile (Website, Sistema, Landing page, etc.).
- Desktop presentation and navigation remain unchanged.
