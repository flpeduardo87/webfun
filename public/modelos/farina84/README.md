# FARINA 84 — Pizza & Cucina — V3

Projeto conceito para portfólio WebFun.

## Páginas
- index.html — home premium
- cardapio.html — cardápio dinâmico com busca, filtros e personalização
- pedido.html — checkout em 3 etapas, cupom e pedido
- acompanhar.html — acompanhamento por código
- contato.html — salão, reservas e contato
- admin.html — pedidos, cardápio e cupons
