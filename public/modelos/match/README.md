# MATCH — Racquet & Wellness Club V3

Projeto conceito premium para portfólio WebFun.

## Páginas
- index.html — home
- modalidades.html — modalidades
- agenda.html — reserva de quadras
- planos.html — planos de associação
- eventos.html — eventos e clínicas
- area-socio.html — portal do sócio
- contato.html — concierge / leads
- admin.html — operação do clube

## Demonstração técnica
Dados ficam em `localStorage` para simular uma aplicação integrada sem backend. Reservas criadas na agenda aparecem na Área do Sócio e no Admin. Bloquear uma quadra no Admin retira seus horários da agenda pública. Leads de formulários aparecem no Admin.
