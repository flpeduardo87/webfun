# AURA Estética Avançada — V3

Projeto conceito premium para portfólio WebFun.

## Páginas
- index.html — Home
- procedimentos.html — Catálogo de protocolos
- procedimento.html?id=bioestimulador — Detalhe dinâmico
- resultados.html — Resultados ilustrativos com disclaimer
- equipe.html — Equipe
- avaliacao.html — Avaliação inteligente
- agendamento.html — Agendamento online em 4 etapas
- contato.html — Contato e captação de lead
- admin.html — Painel administrativo demonstrativo

## Funcionalidades
- Catálogo dinâmico de protocolos via localStorage
- Avaliação inteligente por objetivo
- Agendamento com profissional, data e horário
- Bloqueio demonstrativo de horário já ocupado
- Painel admin com agenda, leads, pipeline e CRUD de protocolos
- Exportação JSON

Dados, profissionais, depoimentos e resultados são fictícios.
