- Diagnóstico executivo em 6 perguntas

- Formulário de contato integrado ao painel
- Cases filtráveis e páginas dinâmicas
- CMS demonstrativo de cases
- Pipeline de leads com alteração de status
- Persistência via localStorage

Projeto conceito. Empresas, métricas e dados são fictícios.
