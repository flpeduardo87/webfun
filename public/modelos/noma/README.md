# NOMA — Imóveis & Arquitetura · V2.3

Projeto-conceito premium para portfólio WebFun.

## Páginas
- `index.html` — Home com motor de busca
- `imoveis.html` — Busca avançada
- `imovel.html` — Detalhe dinâmico + solicitação de visita
- `empreendimento.html` — Lançamento
- `vender.html` — Captação de imóveis
- `favoritos.html` — Favoritos
- `contato.html` — Curadoria/contato
- `admin.html` — Painel administrativo demonstrativo

## Novidades da V2.3
- Motor de busca reposicionado no fluxo do hero, sem sobrepor a seção seguinte.
- Painel administrativo responsivo.
- Cadastro e edição de imóveis.
- Publicar/despublicar imóveis e controlar destaques.
- Exclusão de imóveis.
- Alterações do admin refletidas no catálogo público via `localStorage`.
- Leads dos formulários públicos aparecem no painel.
- Solicitação de visita com data e período preferidos.
- Pipeline simples: Novo → Contatado → Concluído.
- Exportação dos dados da demonstração em JSON.

> Este é um front-end demonstrativo. Em uma versão comercial real, autenticação, uploads, banco de dados, permissões, CRM e integrações seriam implementados no backend.
